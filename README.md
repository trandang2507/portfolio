# Portfolio cá nhân

Website portfolio một trang của **Trần Hải Đăng**, giới thiệu bản thân, kỹ năng kỹ thuật và các dự án đã thực hiện.

## Tính năng

- Điều hướng đến các phần: Home, About, Skills, Project và Contact.
- Hero section có ảnh đại diện và nút xem dự án/liên hệ.
- Hiển thị thông tin cá nhân, học vấn và vị trí hiện tại.
- Danh sách kỹ năng: HTML, CSS, JavaScript, Java, Python, C#, Spring Boot, .NET, Docker, Swagger và Postman.
- Liên kết tới các dự án GitHub: Auction System, Food Ordering System và Todo Task.
- Giao diện tông tối, sử dụng các tài nguyên hình ảnh và biểu tượng cục bộ.

## Công nghệ

- HTML5
- CSS3
- [Font Awesome](https://cdnjs.com/libraries/font-awesome) (tải từ CDN)

## Chạy project

Không cần cài đặt package hay build.

1. Clone repository:

   ```bash
   git clone https://github.com/trandang2507/portfolio.git
   ```

2. Mở thư mục project và chạy file `index.html` bằng trình duyệt.

Để có trải nghiệm phát triển thuận tiện hơn, có thể dùng extension **Live Server** của VS Code để mở trang tại máy cục bộ.

## Cấu trúc thư mục

```text
.
├── index.html       # Nội dung và cấu trúc website
├── style.css        # Kiểu dáng giao diện
├── image/           # Ảnh đại diện, nền và ảnh dự án
└── icon/            # Favicon và biểu tượng kỹ năng
```

## Tùy chỉnh

- Cập nhật thông tin cá nhân, liên hệ và liên kết mạng xã hội trong `index.html`.
- Thay ảnh trong thư mục `image/` nếu muốn sử dụng hình ảnh riêng.
- Chỉnh màu sắc, khoảng cách và bố cục trong `style.css`.
